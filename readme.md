# clima

Apuntes y juego de estudio sobre los climas, en gallego y castellano.

Incluye 15 fichas ilustradas y 75 ejercicios, organizados en cuatro niveles: palabras clave, construcción de frases, explicación con palabras propias y relación entre conceptos.

## Uso

Abre `index.html` en un navegador. El archivo incluye todos los textos, dibujos y ejercicios y funciona sin conexión. La pestaña de idioma conserva la ficha o pregunta actual.

El progreso se guarda en el navegador cuando este lo permite. También se puede descargar y recuperar desde las opciones al final de la página.

## Publicación

El contenido está preparado para GitHub Pages desde la raíz de la rama principal. `.nojekyll` permite servir el HTML directamente.
